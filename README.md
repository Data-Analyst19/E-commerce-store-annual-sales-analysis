**# E-Commerce Annual Sales Analysis**

📊 **# Project Overview**
   This project focuses on analyzing annual e-commerce sales data using Microsoft Excel to identify key sales trends, customer behavior, and business insights.
   The analysis involves cleaning and organizing raw sales data, performing data analysis using pivot tables, charts and creating interactive dashboards and visualizations to understand overall business    performance.

🔎 **#What's in this report**
    original data, pivot tables and chart analysis, interactive dashboard, insights and conclusion.

🎯 **# Objectives**
   Analyze overall sales and order performance.
   Understand customer purchasing behavior.
   Analyze sales based on product categories and regions.
   Identify top-performing products based on gender.
   Create meaningful visualizations and dashboards for better decision-making.

🛠️ **#Tools & Skills Used**

    Microsoft Excel
     Power query for Data Cleaning & Data Transformation
     Pivot Tables and charts
     Dashboard Creation

📈 **#Key Insights**

The project provides insights into sales performance, product trends, customer purchasing patterns, and other important business metrics. The dashboard makes it easier to identify trends and understand which areas contribute most to overall e-commerce performance.

📁 **#Project Files**

Practice_project_vrinda_stores_report.xlsx – Excel workbook containing the cleaned data, analysis, pivot tables, charts and dashboard.

💡 **#Conclusion**

This project demonstrates how Excel can be used as a powerful data analytics tool to transform raw e-commerce data into meaningful business insights. It also showcases my skills in data cleaning, analysis, visualization, and dashboard development.
